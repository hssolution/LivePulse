## 1. 한 줄 요약 (Elevator Pitch)

> **LivePulse는 오프라인 강연·세미나·기업행사 현장에서 청중의 휴대폰을 입력 도구로 만들어,
> 실시간 Q&A·투표·설문으로 일방향 강연을 양방향 소통으로 바꾸는 SaaS이자,
> 강연주최자–전문강연가–행사대행사 3자를 연결하는 강연 비즈니스 매칭 플랫폼이다.**

Slido / Mentimeter / Pigeonhole Live와 동일한 카테고리(Audience Response System)에 속하면서,
한국 시장 특성을 반영해 **강연 매칭 마켓플레이스**를 결합한 하이브리드 모델입니다.

## 3. 해결하려는 문제

### 청중 측
- 오프라인 강연은 일방향이라 청중이 **질문할 타이밍을 놓치거나**, 손을 들고 질문하는 것에 **심리적 부담**을 느낀다.
- 강연 만족도·이해도가 강사에게 전달되지 않아 **강연 품질 개선의 피드백 루프**가 닫혀 있다.

### 강연자 측
- 청중의 반응을 가늠하기 어려워 **강연 페이스 조절**이 감각에 의존한다.
- 설문/투표를 종이로 받으면 **결과 집계·분석에 시간**이 들어 강연 직후 활용이 불가능하다.

### 강연 주최자(기업 HR·교육담당) 측
- 좋은 강연자/대행사를 찾는 채널이 **인맥·소개 위주**여서 검증과 비교가 어렵다.
- 강연이 끝난 뒤 **참석률·만족도·질문 데이터**가 남지 않아 ROI 측정이 모호하다.

### 대행사 측
- 소속 강연자의 일정·실적을 **엑셀로 관리**하고, 신규 기업 고객 발굴 채널이 부족하다.

## 4. 핵심 솔루션 (제품 두 축)

### 축 ①: 실시간 청중 인터랙션 도구 (Audience Response System)

행사 현장에서 **QR코드 한 번**으로 청중이 모바일 페이지에 접속하여 강연자와 실시간 상호작용.

| 기능 | 설명 |
|---|---|
| **Q&A** | 청중이 모바일로 질문 등록 → 강연자/좌장이 선별 → 송출 화면(프로젝터)에 표시. 익명 옵션 지원. |
| **실시간 설문/투표** | 객관식·주관식·평점·O/X 등. 결과를 실시간 차트로 시각화. |
| **송출 화면 분리** | `/broadcast/:code` 라우트로 대형 스크린 전용 화면 제공. 폰트·색상·정렬을 라이브로 조정. |
| **좌장 모드** | `/presenter/:code` 라우트로 좌장이 질문을 큐레이션하고 클릭 한 번으로 송출. |
| **3-템플릿 디자인 시스템** | 참가신청 화면 / Q&A 탭 / 설문 탭 각각의 디자인을 독립 템플릿으로 구성. 브랜딩 맞춤 가능. |
| **참가자 통계** | 시간대별·요일별 참여율, 회원/비회원 비율, 피크시간 분석. |

### 축 ②: 강연 매칭 플랫폼 (Marketplace)

플랫폼이 강연 비즈니스의 3주체를 연결.

| 역할 | 페이지 | 역할 |
|---|---|---|
| **강연 주최자(기업/기관)** | `/lectures` | 검증된 강연가·대행사 DB 탐색, 맞춤 제안 요청, 비교 견적 |
| **전문 강연가** | `/instructors`, `/signup?type=instructor` | 퍼스널 브랜딩 포트폴리오, 의뢰 실시간 알림, 커리큘럼 마케팅 |
| **행사 대행사** | `/agencies`, `/signup?type=agency` | 신규 기업 고객 발굴, 소속 강연가 통합 관리, 입찰·제안 프로세스 |

> 두 축은 **데이터로 연결**됩니다: 매칭으로 성사된 강연이 LivePulse에서 진행되면,
> 참여율·Q&A 수·만족도 같은 **객관적 성과 지표**가 강연자/대행사의 프로필에 누적되어,
> 다음 매칭의 신뢰 자산이 됩니다. (경쟁사가 모방하기 어려운 데이터 해자)

## 6. 주요 사용 시나리오 (3종)

### 시나리오 A — 기업 사내강연
사내 교육담당이 LivePulse에서 강연자 검색 → 의뢰 → 강연 당일 청중이 QR로 입장 →
강연 중 익명 질문 수집(부담 ↓) → 강연 후 만족도 설문 즉시 집계 → 리포트 PDF로 HR에 제출.

### 시나리오 B — 대학교 수업·학생회 투표
교수가 매주 수업에서 LivePulse로 출석 + 이해도 체크. 학생회가 임원선거 투표를
종이 대신 QR + 실시간 그래프로 진행. (홈페이지 카피의 핵심 B2C 진입점)

### 시나리오 C — 컨퍼런스·세미나
행사 대행사가 클라이언트 컨퍼런스를 LivePulse로 진행. 패널 토론에서 청중 질문을
좌장 화면에서 선별 → 메인 스크린 송출. 행사 후 분석 리포트로 클라이언트에 가치 입증.

## 7. 차별점 (Why us, not Slido?)

1. **한국어 우선 / 한국 시장 친화** — 사업자 정보 노출, 한국 결제(포트원+토스페이먼츠), 통신판매업 신고 완료.
2. **매칭 플랫폼 결합** — 도구만 파는 경쟁사와 달리, **강연 자체의 거래(매칭)** 까지 커버. LTV 확장 여지.
3. **템플릿 시스템** — 화면별로 3개 템플릿을 독립 적용 가능해, 행사 브랜딩 자유도가 높음.
4. **무료 진입장벽 제로** — 청중은 로그인·앱설치 불필요. 강연자는 무료 플랜으로 시작 가능.
5. **B2B(기업/기관)와 B2C(대학·동호회) 양면 시장** — 홈페이지 카피("강연뿐만 아니라 모든 모임의 소통을")가 이를 명시.
